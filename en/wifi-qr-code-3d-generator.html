WiFi QR Code 3D Generator

Create a QR code with your network name and password, and download it as a 3D-printed wall plaque. Guests or customers connect by scanning — no reciting the password, no sticky note on the router.

Who this is for

Airbnb hosts, guesthouses, cafés with guest WiFi, or anyone who's tired of repeating their home network password to every visitor — a WiFi QR code solves it at a glance: scan with the phone camera and it connects automatically, no typing required.

Why 3D instead of just a screen

A PNG WiFi code works for printing on paper, but paper peels off, gets wet, or goes missing. A 3D-printed wall plaque with the QR code embossed in two colors (base and code) stays put with the two mounting holes built into the model, lasts for years, and looks a lot more polished than a laminated sheet.

How it works

  1. 1

    Enter your network details

    On the "WiFi" tab of the generator, type the network name (SSID), password, and security type (WPA/WPA2 is standard).

  2. 2

    Choose "Wall plaque" and adjust the size

    The tool calculates live whether the module size is large enough to scan reliably; enlarge the piece if it warns you in red.

  3. 3

    Download the 3MF and print

    Open it in Bambu Studio, PrusaSlicer or Orca Slicer — base and code already have their colors assigned. Hang it with the two mounting points.

Frequently asked questions

Is it safe to put my WiFi password in a public QR code?

The QR code only lets the scanning phone connect to that specific network; it doesn't display the password as plain text unless someone extracts it with a QR reader built for that purpose. If you're concerned, set up a separate guest network and generate the code for that instead.

Does it work with hidden networks?

Yes, check the "Hidden network" box in the generator before downloading.

Can I change the password later?

The code is fixed to the details you entered when you generated it. If you change the network password, you'll need to generate and print a new plaque.

Do I need my own 3D printer?

Not to generate the file — the tool is free and needs no printer. To print it, yes, you'll need a 3D printer (your own or an on-demand printing service).
